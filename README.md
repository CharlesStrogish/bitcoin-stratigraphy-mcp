The **Bitcoin Stratigraphy Data Engine** is a high-security Model Context Protocol (MCP) server that provides AI agents with 15 canonical tools for advanced data analysis, while enforcing cryptographically secure L402 execution budgets and RFC 6962 Merkle flight recorders. 

Standard observability logs can be edited, overwritten, or deleted by system administrators. This engine replaces mutable logs with mathematically non-repudiable state-anchoring, resolving cross-vendor liability disputes and providing the tamper-evident chain of custody required for [EU AI Act Article 12 compliance](https://bitcoin-stratigraphy-dashboard.replit.app/whitepaper).

## 🚀 Features

* **15 Canonical MCP Tools:** Native access to the complete Bitcoin Stratigraphy analysis suite, dynamically pricing tool calls in satoshis.
* **L402 Circuit Breakers:** Physically halt runaway infinite loops. Agents are funded with strict cryptographic macaroons over the Lightning Network. When the budget is exhausted, the protocol drops the connection.
* **Merkle Flight Recorders:** Every agent thought, context window, and tool execution is hashed into an RFC 6962 Merkle tree.
* **OpenTimestamps Anchoring:** Root hashes are mathematically anchored to the Bitcoin base layer, providing immutable, post-hoc proof of multi-agent swarm activity for cyber-liability underwriters.

## 🛠️ Quickstart (Open-Source Usage)

The public MCP server can be used immediately by independent developers. It dynamically invoices tool executions using the L402 protocol.

### 1. Claude Desktop Integration
To give your local Claude app access to the Data Engine and the L402 payment circuit breaker, add this to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "bitcoin-stratigraphy": {
      "command": "npx",
      "args": ["-y", "@bitcoin-stratigraphy/mcp-server"],
      "env": {
        "NWC_URI": "nostr+walletconnect://your-nwc-string-here"
      }
    }
  }
}
```
*Note: You must provide a Lightning Wallet connection (e.g., NWC, Strike, or LND) to pay the L402 satoshi invoices generated by the tools.*

### 2. Standalone NPX Execution
To run the server directly in any MCP-compatible environment without installation:
```bash
npx -y @bitcoin-stratigraphy/mcp-server
```
