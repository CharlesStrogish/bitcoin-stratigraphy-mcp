Free batch POST pricing

Send {"tools":["stratigraphy.get_latest","proof.verify_zk_proof"]} to POST /api/v1/cost for itemized satoshi quotes, a batch total and L402 invoice-generation details. These descriptive selectors are pricing-only mappings to stratigraphy.get and proof.verify.

Quotes do not create or pay invoices. Each paid MCP tool call returns its own HTTP 402 challenge; a batch total is not a multi-tool credential. Examples never pay invoices unless you explicitly configure a payment hook.
